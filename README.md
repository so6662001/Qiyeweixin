### 销售路由两层

**第一层（默认）**：客户档案里的绑定销售优先
- 直接转，最尊重既有关系
- 例外：销售离线/请假/超载/无品类授权 → 走第二层

**第二层（团队池竞争抽签）**：
- 候选池筛选（在线 + 未超载 + 有品类授权 + VIP 必筛选）
- **加权抽签**（softmax + 温度 T）：避免马太效应，新人保底 10%
- **配额限制**：每销售每日新单配额 8 个，超额自动溢出

### 销售评分 7 个维度

| 维度 | 权重 |
|---|---|
| 成交转化率 | 25% |
| 月成交吨位/金额 | 20% |
| 回款 DSO（反向） | 15% |
| 客户 NPS | 10% |
| 平均响应时长（反向） | 15% |
| 拒单率（反向） | 10% |
| 当前负载（反向） | 5% |

综合分 0~100，团队 leaderboard 实时刷新，销售可见自己分数，**客户不可见**。

### SLA + ACK 转派

| 时间 | 动作 |
|---|---|
| T+5min ACK 超时 | 自动转池下一位（原销售不扣分） |
| T+15min 已 ACK 未回 | 内部提醒 |
| T+30min 仍未回 | 升级主管 + 客户安抚 |
| T+60min 严重超时 | 团队负责人介入 |

主动拒接 → `decline_rate++` → 评分降。形成"愿接 + 接好 → 评分高 → 优质单更多"正向循环。
