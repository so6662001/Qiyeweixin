## v12 核心 2：自我学习 + 不能 AI 幻觉

### 三层分工架构

| 层 | 职责 | 输出 | 会编数字吗 |
|---|---|---|---|
| **统计学习层** | 聚合事实数据 → 确定性指标（众数/中位数/接受率/转化率） | 数字 + 样本数 + 置信度 | **不会**（数学计算） |
| **规则决策层** | 把指标作为规则参数；规则本身仍人编写 | 决策结果 | **不会**（按规则执行） |
| **LLM 解释层** | 用指标 + 决策 → 话术 | 自然语言文本 | **绝不出数字** |

### 4 学 / 4 不学

**4 学**：客户画像 / 策略效果 / 行情季节 / 销售经验沉淀

**4 不学**：
- 不学"该报多少钱"（价格只能从 cost + strategy 合成）
- 不学"该让多少"（让步幅度由让步预算和曲线生成）
- 不学"何时破红线"（成本/合规红线不可学）
- 不学客户类型/黑白名单分级（必须人审）

### 5 道幻觉防护栏

1. **数字溯源**：每数字字段标 source + 证据
2. **置信度门槛**：< 0.7 不使用，回退默认
3. **冷启动保护**：样本数 < 10 不用学习结果
4. **Drift 监控**：变化 > 20% 暂停 + 人工 review
5. **A/B 灰度**：5% → 20% → 100% 逐步放量

### 关键防御：LLM 占位符强制

```
LLM 输出："为您锁价 {{LOCK_HOURS}} 小时，让 {{DISCOUNT}}/吨"
渲染后：  "为您锁价 23 小时，让 ¥15/吨"
后置 DLP：扫到 LLM 输出未占位符的纯数字 → REJECT
```

数字**永远从结构化方案渲染**，LLM 不能直出数字。

### 学习足迹（销售可见，客户不可见）

```
本次报价学习足迹（销售可见）：
  ├ 默认 length=12m ← 客户最近 8 次 7 次（confidence 0.88）
  ├ 策略=volume_driven_lowest ← 客户量型 + 平均订单 80t
  ├ 锁价 23h ← 客户决策中位数 22h（confidence 0.81）
  ├ 推荐替代=永钢 ← 同档异厂接受率 0.73
  └ 让步预算 ¥45/t ← 行业均值 + 客户类型修正
     （cost_redline 永不学习，硬保护）
```
