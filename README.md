## v14 本次大批量需求确认（60 个决策）

需求方一次性确认了 v7~v13 的 60 个待确认问题。引出 8 个架构变化：

### 1. Configuration Center（企业配置中心，最重要）
本次决策 25+ 次提到"可配置"，因此新增多租户配置中心承载所有可调参数：
- 类型：PRICING / NEGOTIATION / ROUTING / LEARNING / RESERVATION / SUBSTITUTE / SLA
- 版本化 + 双人复核 + 灰度（5%→20%→100%）+ 热加载
- business_floor 类型强制审计

### 2. 客户细分（segment）+ 毛利底线差异化
- **下级经销商**（dealer）：以挂牌价为成本基线，毛利底线 ¥10/吨
- **终端企业**（terminal）：以实际成本核算，毛利底线 ¥200/吨
- 整单 Optimizer 按 segment 查底线
- 企业可配置

### 3. Sales Style Profile（议价话术个人风格）
- 每销售一份风格档案（口头禅 / 语气强度 / 常用比喻 / few-shot）
- 议价 LLM Prompt 注入
- 仍走数字占位符强制（不绕过幻觉防护）

### 4. Competitor Credibility Score（虚假竞品积分系统）
- 每客户每竞品维护 0~100 分
- 提竞品但回头买我们 → 扣分
- 严重虚价 → 销售提报 → 主管审批 → **专项黑名单**（与普通黑名单分离）
- 强制审计日志（证据链 + 审批链）

### 5. 改量规则细化
- 锁价后单次 ±5% 内 / 累计 ±10% 内 → 自动放行
- 单次 ≤ 5% 但累计 > 10% → 销售确认
- 单次 > 5% 且累计 > 10% → 主管审批
- **减量退价分档**（不一刀切）：
  - ≤ 5%：保持原锁价
  - 5~15%：回到无量阶梯标准档
  - 15~30%：标准档 + 加 ¥10/t
  - > 30%：销售判断 + 整单 Optimizer 重校
- 每个版本都保留

### 6. 销售级别体系（junior / mid / senior）
- 配额差异化：junior 5 / mid 8 / senior 12
- **入职时间衰减保底**：≤3 月 15%、≤6 月 10%、≤12 月 5%、> 12 月 0%
- 客户类型授权差异化：junior 主练新客 + 流失；senior 可接战略 + VIP

### 7. 学习参数收紧（更稳）
- 冷启动样本数：**10 → 60**
- 学习窗口：**7 天短窗 + 90 天长窗双轨**
- A/B 灰度周期：**7 天 → 30 天**
- 学习足迹：**仅主管可见**（销售不可见）
- 销售个人**不能看自己的学习指标**，但能看客户画像
- 保留"建议销售考虑改客户类型"功能（不自动改）

### 8. 可机器报价 SKU 白名单
- v10 的"未定价"路径具体化为白名单查询
- 不在白名单 → 转销售人工
- 销售可提报新增 + 主管审批
- 6 个月 review
