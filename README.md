## v8 改量能力（Quote Amendment）

### 报价生命周期状态机

```
DRAFT → ACTIVE → AMENDING → RESCORED → ACTIVE'(v+1)
         ↓                            
        LOCKED → LOCKED+AMENDING（需销售审批）
         ↓
        EXPIRED / SUPERSEDED
```

每次改量生成新版本（不覆盖），客户能看到「原方案 vs 新方案」对比，销售可手动回滚。

### 改量 8 种情景

| # | 类型 | 处理 |
|---|---|---|
| 1 | 加量到下一阶梯 | **AUTO 自动调价** |
| 2 | 加量超库存 | **MANUAL 转销售拆批** |
| 3 | 加量超 Auto 上限 | **升档 Assisted/Manual** |
| 4 | 减量但 ≥ MOQ | **AUTO 上浮** |
| 5 | 减量跌穿 MOQ | **CUSTOMER_CHOICE 给 2 选项**（加量/不过磅）|
| 6 | 减量到 0 | **REJECT 撤单** |
| 7 | 议价中改量 | **走议价引擎**（量价互换） |
| 8 | 锁价后改量 | **MANUAL 销售审批** |

### 改量五档决策

| 决策 | 条件 |
|---|---|
| AUTO | 幅度 ≤ ±10% + 合规全过 + 非锁价 + 非议价 |
| ASSISTED | 10~30% / 阶梯变 / 拼仓变 / 库存吃紧 |
| CUSTOMER_CHOICE | 跌穿 MOQ |
| MANUAL | 库存不足 / 锁后 / 频次超限 / 整单破底 |
| REJECT | new_qty == 0（撤单） |

### 锁价后改量特殊规则

- **加量**：通常允许，新增部分销售决定是否享受量阶梯
- **减量**：默认不退价（保护承诺），销售可豁免
- **改规格/目的地/产地**：原锁价作废，作为新询价处理
- 必走销售审批工单 + 主管复核 + 30 天复盘

### 改量频次防护

```yaml
per_quote_max: 3              # 同 Quote 改量上限
per_session_warning: 5         # 同 Topic 改量警告
per_day_per_customer_max: 10   # 单客户单日上限
```

≥ 3 次 → 转销售 + ghost_score↑ + 软干预 L4
