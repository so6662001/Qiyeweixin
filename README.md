# Qiyeweixin

钢铁贸易行业 · 企业微信智能机器人项目。

当前阶段：**设计阶段**（尚未开发）。详细设计见 [`DESIGN.md`](./DESIGN.md)（v2，已根据需求方反馈优化）。

## 一句话方案

**企业微信「自建应用」+「微信客服」双通道** + **LLM（DeepSeek/通义千问）编排** + **Function Calling 调现有业务 API** + **Topic 状态机做跨天多轮对话**。

- 内部员工 → 企业微信自建应用对话
- 外部客户 → 普通微信里通过微信客服对话（官方合规路径，不走个人微信号协议）
- 业务 API 不改造：由 Bot 内的「业务 API 适配层（ACL）」做字段映射、参数补齐、单位换算、缓存
- LLM 仅做理解与拼装，**所有价格/库存/订单号必须来自工具调用**，禁止编造
- 写操作（下单/锁价）一律二次确认 + 60s 反悔窗
- 钢铁贸易技能包：询价 / 报价 / 锁价 / 下单 / 订单进度 / 库存 / 物流 / 磅单 / 质保书 / 对账 / 行情订阅
