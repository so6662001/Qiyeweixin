## v6 报价协作三档

| 档位 | 谁出价 | 触发 |
|---|---|---|
| **Auto** 即时自动 | Bot 直接报 | 白名单/标准客户 + 标准品 + 量在阈值 + 库存充足 + 风险低 |
| **Assisted** 辅助 | Bot 出方案 → 销售一键确认 | 大多数情况 |
| **Manual** 人工 | 销售全程，Bot 仅传话 | 黑名单 / 超大单 / 非标 / 风险高 |

## v6 行为干预（白嫖客户管理）

**核心理念**：不抱怨、不指责、靠**差异化体验**让客户自己悟。

| 层 | 触发 | 动作 |
|---|---|---|
| L1 隐性配额 | 24h 内同规格重复询价 | 直接引用上次报价 |
| L2 锁价缩短 | ghost_score ≥ 0.5 | 锁价从 24h → 6h |
| L3 阶梯隐藏 | ghost_score ≥ 0.5 | 不展示量阶梯 |
| L4 销售关怀 | ghost_score ≥ 0.6 / 5 次未成交 | 销售主动联系（系统提供建议话术） |
| L5 策略降档 | ghost_score ≥ 0.7 | 降为标准价；客户感受到"没那么有竞争力" |

**反向激励**：高转化客户体验明显更爽（更快、更长锁价、更优阶梯、可见 VIP）→ 让"忠诚红利"和"白嫖代价"做成可对比的体验差。

**客情防火墙**：永远不公开 ghost_score；活跃下单 30 天自动恢复优待。
