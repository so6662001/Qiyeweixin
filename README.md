## v13 留货下单

### 锁价 / 留货 / 下单 三阶段对比

| 维度 | 锁价 | **留货 (v13)** | 正式下单 |
|---|---|---|---|
| 价格锁定 | ✅ | ✅ | ✅ |
| 库存独占 | ❌ | **✅**（货被分配给该客户） | ✅ |
| 定金 | 不收 | **10~30%** | 余款付清 |
| 期限 | 24~48h | **1~7 天** | 直接进生产 |
| 反悔成本 | 自由 | **扣违约金** | 走变更流程 |
| 议价 | 可（v7） | **默认拒绝**（行情大跌特批） | 不议价 |

### 留货状态机

```
DRAFT → PENDING_DEPOSIT → ACTIVE → CONVERTED（转单）
                ↓                ↓
           CANCELLED_NO_DEPOSIT  EXPIRED（自动释放 + 违约金）
                                 CANCELLED（按合同退定金）
```

### 5 项资格校验

1. 客户名单：黑名单/冻结 → 拒
2. 信用额度：≥ 定金需求
3. 未结清留货数：< 阈值（默认 3）
4. 库存可独占：available ≥ 留货量
5. Quote 状态：ACTIVE / LOCKED

### 定金规则（品类 × 客户类型）

| 品类 | 默认 | 战略客户 | 黑名单 |
|---|---|---|---|
| 螺纹钢 / 普通板材 | 10% | 5% / 免 | 禁 |
| 卷板 / 中厚板 | 15% | 10% | 禁 |
| 不锈钢 / 特殊钢 | 30% | 20% | 禁 |

大单地板：> 100w 元必须 ≥ 10%（即使战略客户）。

### 期限规则

| 客户类型 | 默认 | 上限 |
|---|---|---|
| 战略 | 5 天 | 7 天（审批） |
| 白名单 | 3 天 | 5 天 |
| 普通 | 3 天 | 3 天 |
| 新客 | 1 天 | 2 天（审批） |
| 信用警告 | 1 天 | 1 天 |

### 过期工单

```
T-24h  Bot 提醒客户
T-12h  Bot 再提醒 + [转单/延期/取消]
T-1h   紧急提醒 + 通知绑定销售
T+0    自动释放库存 + 按合同处理定金
```

定金处理三模式（公司选）：扣 50%+冲下次 / 全扣 / 全退

### 库存独占（Inventory Matcher 扩展）

```
total = available + reserved + sold + 其他

留货创建 → available -= qty; reserved += qty
转单 → reserved -= qty; sold += qty
过期/取消 → reserved -= qty; available += qty
```

与 ERP 分钟级对账，差异告警。

### 留货中操作限制

| 操作 | 处理 |
|---|---|
| 加量 + 库存够 | 追加定金，扩展原留货 |
| 加量 + 库存不够 | 转销售拆批 |
| 减量 | 按合同退部分定金 |
| 改规格/产地 | 取消原留货 + 违约金 + 新询价 |
| 议价 | **默认拒绝**；行情大跌转销售特批 |
| 申请延期 | 销售/主管审批 |
| 转下单 | 余款付清自动转 |

### 自我学习与留货

**学**：客户留货后转单率（高 → 信任度↑，下次定金可降）、典型留货时长、留货后改量频次

**不学**：留货定金率、留货期限上限、违约金率（列入硬白名单）
