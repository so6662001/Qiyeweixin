## v11 替代料推荐

### 替代关系 7 种类型

| 类型 | 例子 | 推荐力度 |
|---|---|---|
| 同档异厂 | 沙钢 ↔ 永钢 同 HRB400 | 强推 |
| 同档异定尺 | 12 米 ↔ 9 米 ↔ 倍尺 | 中推 |
| 同档品质差 | 标准品 ↔ 长锈轻锈 ↔ 优级 | 中推 |
| 向上兼容 | HRB400 → HRB500；Q235 → Q355 | 弱推 |
| 向下兼容 | HRB400E → HRB400（去抗震） | 谨慎 |
| 规格相近 | Φ25 ↔ Φ22 | 谨慎（工程禁） |
| 国标/外标等价 | Q235B ↔ SS400 ↔ A36 | 中推 |

### 推荐时机 3 场景

| 客户原 spec 状态 | 默认策略 |
|---|---|
| **完全有货** | 不主动推（避免砸自己价）；议价中可作让步货币；战略客户可主动推建立信任 |
| **部分有货** | 推"拼方案"（原 30t + 替代 20t） |
| **完全无货** | 替代是主推（替代不成才转人工） |

### 客户接受度 3 维过滤

| 维度 | 说明 |
|---|---|
| 客户类型 | 工程方默认不推向下/相近；贸易商/加工厂可推 |
| 历史接受 | 历次拒绝 ≥ 3 次同类 → 该类永不推 |
| 用途场景 | LLM 抽取（工程/配件/出口）；工程严格模式 |

### 3 个潜在大坑与规避

1. **偷偷换货** → 客户投诉
   - 对策：必须明示替代关系；客户必须明确确认；合同单独条款；签收清单
2. **工程方按图纸拒收** → 退货纠纷
   - 对策：客户档案 `accepts_substitute=false` 永不推；用途含"工程" → 严格模式
3. **销售当原料卖** → 合规问题
   - 对策：Bot 内永远显示"替代方案 + 原品对比"；合同条款单独标注；审计追溯

### 议价让步货币扩展为第 9 维

```
v7~v10 让步货币 8 维：价 / 量 / 时 / 运 / 期 / 质 / 赠 / 组
v11 新增第 9 维：substitute（替代料）— 不动主价，换更便宜替代，客户得到等价让步，我方毛利可能反增
```
