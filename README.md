# Qiyeweixin

钢铁贸易行业 · 企业微信智能机器人项目。

当前阶段：**设计阶段**（尚未开发）。详细设计见 [`DESIGN.md`](./DESIGN.md)（v4，新增多模态询价解析）。

## 一句话方案

**企业微信「自建应用」+「微信客服」双通道** + **LLM（DeepSeek/通义千问，含 VL 视觉模型）编排** + **Function Calling 调现有业务 API** + **Topic 状态机做跨天多轮对话** + **Workflow 工单引擎处理异步流程** + **Inbound Webhook 接收业务系统反向通知** + **Media Pipeline 处理文件/图片** + **Inquiry Parser 解析询价 4 种输入**。

## 对齐的 8 项实际后端能力（v3+ 对齐）

| # | 能力 | 形态 |
|---|---|---|
| 1 | 查留货订单 | 同步查询 |
| 2 | 查欠款 | 同步查询 |
| 3 | **询价**（销售在 ERP 里报价） | **异步工单 + 业务系统回调**；**支持文字/图片/Excel/PDF 4 种输入**；**批量 SKU** |
| 4 | 查装车重量（磅单） | 同步查询 |
| 5 | 要材质书 | 同步查询 + PDF 下发 |
| 6 | 接收/查结算单 | 业务系统推 + 客户回确认（双向 + PDF） |
| 7 | 接收客户付款凭证 | 入站图片/PDF + OCR + 工单转财务 |
| 8 | 提醒销售发货 | 跨用户消息转发 + 工单 |

## v4 关键能力：询价多模态解析

| 输入 | 处理 |
|---|---|
| 文字 | LLM 抽槽位 |
| 图片 | Qwen-VL / DeepSeek-VL + OCR 双校验 |
| Excel | openpyxl 解析 + LLM 列头映射 + 单位归一 |
| PDF | 文本 PDF 直抽；扫描 PDF 转图走 VL |

→ 统一产出 `InquiryDraft { items: InquiryItem[] }` → **强制回显客户逐项确认** → 才提交 ERP 询价单 → 销售在 ERP 报价 → `quote.ready` 反向回调 → Bot 主动推回客户。

## 关键设计约束

- 内部员工 → 企业微信自建应用；外部客户 → 普通微信里通过微信客服
- 业务 API 不改造：ACL 层做字段映射、参数补齐、单位换算、缓存、重试
- LLM/VL 仅做理解、解析、拼装，**所有价格/欠款/重量/订单号必须来自工具调用**，禁止编造
- 询价解析准确率 ≥ 90%，剩余通过人工确认补齐；强制回显 + 客户确认才能提交
- 异步流程走 `/biz/event` Inbound Webhook + Workflow Engine
- 写操作一律二次确认 + 60s 反悔窗
- 文件全程 KMS 加密 + 临时签名 URL；询价 1y / 财务 5y 留存
