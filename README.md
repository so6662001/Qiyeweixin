## v9 调整：OCR 统一通义千问

| 场景 | 之前（v4~v8） | v9 |
|---|---|---|
| 询价图片表格识别 | Qwen-VL-Max + 阿里云/腾讯云 OCR 双校验 | **Qwen-VL-Max 一站式** |
| 扫描 PDF 询价 | 转图 → Qwen-VL + PaddleOCR 备选 | **Qwen-VL-Max 直接处理** |
| 付款凭证 OCR | 阿里云通用 OCR / 腾讯云票据 OCR | **Qwen-VL-Max** |
| 磅单/合同照片 | 暂未明确 | **Qwen-VL** |

**好处**：单一供应商、集成简单、账单清晰、token 计费方便、出口白名单收敛。

**风险与对策**：
- 单供应商风险：DashScope 企业级 SLA 配额 + Qwen-VL-Max → Plus 内部降级 + 失败转人工
- 计费失控：file hash 缓存 + 客户/日配额 + 图片预压缩
- 非标识别下降：规则正则二次校验关键数字字段 + 不唯一反问 + 财务最终确认

**模型路由**：
- 主力：`Qwen-VL-Max`（询价表格、扫描 PDF、付款凭证）
- 降级：`Qwen-VL-Plus`（限流时备用，准确率略降但能跑）
- 应急（演进项）：保留 DeepSeek-VL 作未来备选，不在 v9 上线
