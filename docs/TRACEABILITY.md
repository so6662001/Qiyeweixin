## 14. 如何使用本矩阵

1. **核对遗漏**：逐行检查"需求"列，确认是否为你的真实意图；如发现遗漏或理解偏差，指出对应 ID
2. **开发追踪**：开发时按 ID 对照设计章节实现
3. **验收对照**：每项需求的验收标准见 [`ACCEPTANCE.md`](./ACCEPTANCE.md)
